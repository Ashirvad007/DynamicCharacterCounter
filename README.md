# Real-Time Character Counter

## Project Description

This project is a Character Counter application built using HTML, CSS, and JavaScript. It allows users to type messages in a text area while displaying the number of characters entered and remaining in real time.

## Features

* Live character counting
* Displays maximum character limit
* Updates count while typing
* Prevents users from exceeding the limit
* Warning message when limit is reached
* Simple and attractive user interface

## Technologies Used

* HTML
* CSS
* JavaScript

## Functionalities

1. Displays the maximum allowed character count.
2. Updates character count dynamically.
3. Shows remaining characters.
4. Restricts input beyond the specified limit.

## How to Run

1. Download or clone the repository.
2. Open the `index.html` file in any web browser.
3. Start typing in the text area to see the live counter.
